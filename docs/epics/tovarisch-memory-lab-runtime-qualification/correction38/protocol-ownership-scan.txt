## Compatibility Cleanup (P0-9)

`cmd/canary.AllowedErrorClasses` is currently a defensive-copy helper map
built from `canarycontrol.AllErrorClasses()`. It exists for legacy test
compatibility. CORRECTION38 keeps it because existing tests reference it,
but it is not a parallel vocabulary authority — it is a derived accessor.

No active production caller depends on `cmd/canary.AllowedErrorClasses`
outside of `cmd/canary/control_test.go`.
