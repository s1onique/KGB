## Permitted Dockerlab-owned concerns (retain)

- Docker Engine API calls (exec create/attach/start/inspect)
- exec attachment and stream handling
- exec inspection
- transport context handling (timeouts, cancellation, deadlines)
- bounded stdout/stderr capture (with explicit limits)
- bounded diagnostic rendering

## Forbidden Dockerlab-owned concerns (must delete or replace)

- protocol schema (duplicate of canarycontrol.ControlEnvelope)
- operation vocabulary (duplicate of canarycontrol.Operation)
- error-class vocabulary (duplicate of canarycontrol.ErrorClass)
- payload structs (duplicate of canarycontrol.HealthPayload/StatePayload/WorkloadPayload)
- JSON decoding semantics (duplicate of canarycontrol decoder)
- retry classification (duplicate of canarycontrol.IsRetryable)
- argv construction (duplicate of canarycontrol.BuildArgv)
- manual envelope validation (duplicate of canarycontrol.ValidateControlEnvelope)

## Migration Status (CORRECTION38)

NOT migrated in this bounded ACT. The dockerlab migration requires
updating hundreds of dependent tests across dockerlab and the
tovarisch-memory-lab CLI. Deferred to a future ACT that focuses
