# Zig 0.16 Rules

## Target

KGB targets Zig 0.16.x for `tovarisch`.

## Key Rules

- Do NOT use stale Zig 0.11–0.14 examples.
- Do NOT downgrade Zig to match old code.
- Always read `docs/tooling/zig-0.16-field-manual.md` before editing Zig.
- Inspect existing working files (`tovarisch/src/*.zig`, `tovarisch/build.zig`) before inventing APIs.
- Keep `main.zig` as process boundary only; CLI/status logic belongs in separate modules.

## Zig Learning Protocol

If you hit any Zig 0.16-specific issue (API mismatch, stdlib rename, test harness problem, IO/process surprise):

1. Continue solving the task.
2. Do not downgrade Zig.
3. Document the observation in your response:
   - symptom
   - wrong assumption
   - working fix
   - files affected
   - promote to field manual? (yes/no)
4. If reusable, also update `docs/tooling/zig-0.16-observations.md`.

## Known Traps

- Old stdout pattern `std.io.getStdOut().writer()` — NOT valid in Zig 0.16.
- Old allocator `std.heap.GeneralPurposeAllocator` — not needed for trivial CLI.
- Old `pub fn main() void` — use `pub fn main(init: std.process.Init) !void`.

See `docs/tooling/zig-0.16-field-manual.md` for known-good patterns.
